# 🐍 Snake Man - AI Maze Game

## 🎮 Overview
Snake Man is an AI-based maze game where a human player must escape a maze while being chased by an intelligent snake using pathfinding algorithms.

## 🚀 Features
- 🧠 AI Snake using pathfinding (Manhattan logic)
- 🎯 60 Levels with increasing difficulty
- 🪙 Score-based progression
- 🌀 Exit portal unlock system
- 🎨 Player color customization
- ⚡ Power-ups and game effects
- 🎮 Smooth animations and UI

## 🛠️ Tech Stack
- React (Vite)
- Tailwind CSS
- JavaScript
